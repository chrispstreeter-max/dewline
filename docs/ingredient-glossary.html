Ingredient glossary

The ingredient glossary is an A to Z page of every ingredient you use: what it does, its INCI name and which products contain it. Shoppers can search it, filter it by category and jump to a letter.

Create the glossary page

  1. In your Shopify admin, go to Online Store > Pages and select Add page.
  2. Enter a title, for example "Ingredients".
  3. Under Theme template, choose ingredients (the page.ingredients template).
  4. Select Save.
  5. Add the page to your menu in Online Store > Navigation.

The template ships with 14 sample entries, from Azelaic acid to Zinc oxide. Edit or remove them in the theme editor.

Tip: if the page handle is ingredients (the URL ends in /pages/ingredients), the Key ingredients link on the default product template already points to it.

Add an entry

  1. Go to Online Store > Themes and select Customize.
  2. From the page selector at the top, choose Pages > ingredients.
  3. Under the Ingredient glossary section, select Add block > Ingredient.
  4. Fill in the entry:
    • Name: the everyday name, for example "Niacinamide". This decides the letter it is listed under.
    • Also known as: the INCI name or other names, for example "Vitamin B3". Shoppers can search these too.
    • Category: see the list below.
    • Role: two or three words, for example "Oil control".
    • Description: what it does, in plain language.
    • Typical use: optional, for example "2–5%".
    • Image: optional.
    • Find it in: up to four products that contain it. They show as small links with images.
  5. Select Save.

Entries are grouped by the first letter of their name automatically. Within a letter, they keep the order of the blocks in the sidebar, so drag them to sort alphabetically. Names that start with a number or symbol are grouped under #.

Categories

Each entry belongs to one category. The filter chips above the list only show categories you have used.

  • Hydrators
  • Actives
  • Soothers
  • Antioxidants
  • Exfoliants
  • Sunscreen filters
  • Supplements

Link to an ingredient

Every entry has its own link: the page URL plus # and the ingredient name in lowercase, with spaces turned into hyphens.

Ingredient name Link
Niacinamide /pages/ingredients#niacinamide
Hyaluronic acid /pages/ingredients#hyaluronic-acid
Vitamin C /pages/ingredients#vitamin-c

Use these links in product descriptions, blog posts, the Key ingredients block or the Ingredient spotlight section on your home page. If a search or filter is hiding the entry, the page clears it so the shopper lands right on it.

Tips

  • Keep names consistent with your product pages, so a shopper who reads "Niacinamide 5%" on a product finds "Niacinamide" in the glossary.
  • Fill in Also known as with the INCI name. Shoppers often search what they read on the packaging.
  • Do not use the same name twice. Each name becomes a link, and links must be unique.

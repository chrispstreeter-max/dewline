Styles guide

Dewline comes with three styles. Each style sets the colors, fonts, corner radius and button shape. Sections, templates and your content are the same in every style, so you can pick the look that fits your brand and still use every feature.

Dewline

Clean and clinical, for skincare brands.

Setting Value
Heading font Instrument Serif
Body font Instrument Sans
Heading size 110%
Heading letter case Default
Corner radius 14 px
Button shape Pill

Color schemes:

  1. Scheme 1: bone background (#F5F3EE), ink text (#1C2321), sage accent (#3E6555), ink buttons.
  2. Scheme 2: mist background (#E6EEE9) with deep green buttons. Good for highlight sections.
  3. Scheme 3: dark ink background (#1C2321) with bone text and a soft dew accent (#A8CBB9).
  4. Scheme 4: white background with sage buttons. Good for product grids.

Best for: serums, moisturizers, cleansers and dermatologist-led brands that want a calm, trustworthy look.

Pigment

Bold color and confident type, for makeup brands.

Setting Value
Heading font Syne Bold
Body font Manrope
Heading size 100%
Heading letter case Uppercase
Corner radius 4 px
Button shape Square

Color schemes:

  1. Scheme 1: white background, near-black text (#141414), berry accent (#B3174F).
  2. Scheme 2: soft pink background (#FBE7EF) with berry buttons.
  3. Scheme 3: black background with white text and a bright pink accent (#FF7AA6).
  4. Scheme 4: full berry background (#B3174F) with white text and buttons.

Best for: lip, eye and complexion products, shade ranges and brands with strong campaign imagery.

Tonic

Warm and earthy, for supplements and wellness brands.

Setting Value
Heading font Gloock
Body font Figtree
Heading size 100%
Heading letter case Default
Corner radius 22 px
Button shape Rounded

Color schemes:

  1. Scheme 1: oat background (#F3EDE3), dark brown text, rust accent (#8F4A17), forest green buttons (#2E3A2B).
  2. Scheme 2: pale green background (#E5EBD6) with forest buttons.
  3. Scheme 3: forest background (#2E3A2B) with oat text and a turmeric accent (#E8B07A).
  4. Scheme 4: cream background with rust buttons.

Best for: vitamins, powders, teas and wellness rituals. Pair it with the Supplement facts block on product pages.

Settings every style shares

All three styles start with the same product card, cart and search settings: portrait product images, a second image on hover, star ratings, quick add, a cart drawer and a free shipping bar at 50 in your store currency. Change any of these in Theme settings.

Switch to another style later

You have two options:

  1. Add the theme again: from the Theme Store, add Dewline with the other style. This gives you a fresh copy to compare side by side. Your current theme keeps working.
  2. Change the style in the theme editor: open Theme settings and use the theme style option to switch. This replaces your theme settings (colors, fonts, layout), so note any custom colors first.

With option 2, the content you added to sections stays where it is. With option 1, the new copy starts with the demo content, so you set it up again.

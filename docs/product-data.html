Product data with metafields

Dewline's product blocks (key ingredients, results, supplement facts, free from, how to use, the full ingredient list and routines) read their content from metafields. You create each metafield once, fill it in on every product, and each product page shows its own data.

Good news: the default product template already connects these blocks to the metafields below. If you create the definitions with exactly these namespaces and keys, the blocks fill in on their own. You only need to connect them by hand if you use different keys.

The metafields Dewline expects

Name (your choice) Namespace and key Type Used by block
Key ingredients custom.key_ingredients Multi-line text Key ingredients
Ingredients custom.ingredients Multi-line text (or Rich text) Ingredient list
Free from custom.free_from Single line text Free from
How to use custom.how_to_use Multi-line text How to use
Results custom.results Multi-line text Results timeline
Supplement facts custom.supplement_facts Multi-line text Supplement facts
Morning routine custom.routine_am Product, list of products Routine (Morning)
Evening routine custom.routine_pm Product, list of products Routine (Evening)
Product subtitle descriptors.subtitle Shopify standard definition Subtitle, product cards

Create a metafield definition

Repeat these steps for each row in the table.

  1. In your Shopify admin, go to Settings > Custom data.
  2. Under Metafield definitions, select Products.
  3. Select Add definition.
  4. Enter a Name, for example "Key ingredients".
  5. In Namespace and key, enter the exact value from the table, for example custom.key_ingredients.
  6. Select the Type:
    • For multi-line text, choose Text, then Multi-line text.
    • For single line text, choose Text, then Single line text and keep One value.
    • For routines, choose Product, then select List of products.
  7. Select Save.

Add the Shopify subtitle

The subtitle is a standard Shopify definition, so you do not type the key yourself.

  1. Go to Settings > Custom data > Products and select Add definition.
  2. Choose Product subtitle from the standard definitions. Its key is descriptors.subtitle.
  3. Select Save.

The Subtitle block shows it under the product title, and product cards show it when Theme settings > Product cards > Show product subtitle is on. Example: "Barrier serum, 30 ml".

Fill in a product

  1. Go to Products and open a product.
  2. Scroll to the Metafields card near the bottom.
  3. Fill in each field using the formats below.
  4. Select Save.

Line formats each block expects

Each block reads one line at a time. Press Enter (Return) between lines. The vertical bar | separates parts of a line.

Key ingredients

One ingredient per line as Name | what it does.

Niacinamide 5% | Calms redness
Ceramide NP | Repairs the barrier
Panthenol | Soothes and softens
  • If the last word of the name contains %, it shows as a small dose label next to the name.
  • The part after | is optional.
  • The block's Icon setting picks the icon. Alternate cycles through drop, leaf and flask.
  • Set Link and Link label to point shoppers to your ingredient glossary.

Results timeline

One result per line as Time | result.

2 weeks | 94% said skin felt more hydrated
4 weeks | 88% saw less redness
8 weeks | 81% said pores looked smaller
  • If the result starts with a word containing %, that number shows large as the headline stat.
  • Lines without | are skipped.
  • Use the block's Disclaimer setting to say where the numbers come from. Only publish results you can support.

Supplement facts

The block builds an accessible facts table from three kinds of lines:

Serving size | 1 scoop (5 g)
Servings per container | 30
Vitamin C | 500 mg | 556%
Magnesium | 120 mg | 29%
Ashwagandha root extract | 300 mg | †
* Percent Daily Values are based on a 2,000 calorie diet.
† Daily Value not established.
  • Two parts (Label | value): serving lines at the top of the table, like serving size and servings per container.
  • Three parts (Nutrient | amount | % Daily Value): one row per nutrient.
  • No | at all: a footnote under the table. Use this for the * and † notes.

Important: a nutrient line must always have three parts. If there is no Daily Value, put † in the third part. A nutrient line with only two parts shows up with the serving lines instead.

Free from

A single line, separated by commas:

Fragrance, Parabens, Sulfates, Silicones

Each item shows as a badge with a check mark.

How to use

One step per line:

Apply 2 to 3 drops to clean, damp skin.
Press in gently with your palms.
Follow with moisturizer.

The block's Time of day setting adds Morning or Evening labels. Turn on Show as collapsible row to tuck it into an accordion.

Ingredient list

Paste the full INCI list exactly as it appears on your packaging:

Aqua (Water), Glycerin, Niacinamide, Ceramide NP, Panthenol, ...

It shows inside a collapsible row called "Full ingredient list".

Morning and evening routines

Pick the products in the order they are used, up to eight for each routine. See Routines and subscriptions for how the block works.

Connect a block to a metafield

Do this if you used different keys, or if you add one of these blocks to another template.

  1. Go to Online Store > Themes and select Customize.
  2. From the page selector at the top, choose Products > Default product (or your product template).
  3. In the left sidebar, select the block, for example Key ingredients.
  4. Next to the setting you want to fill, for example Ingredients, select the Connect dynamic source icon.
  5. Choose the metafield, for example Key ingredients. Only metafields of a matching type show in the list.
  6. Select Save.

Which setting connects to which type:

Block Setting Metafield type
Key ingredients Ingredients Multi-line text or Rich text
Results timeline Results Multi-line text or Rich text
Supplement facts Facts Multi-line text or Rich text
How to use Steps Multi-line text or Rich text
Ingredient list Ingredients Multi-line text or Rich text
Free from Items Single line text
Routine Products (Morning, Evening) List of products
Subtitle Text Single line text (descriptors.subtitle)

Empty blocks hide themselves

If a product has no value for a metafield, the block does not show on that product. You can keep every block in one product template for skincare and supplements alike. A face serum simply will not show supplement facts.

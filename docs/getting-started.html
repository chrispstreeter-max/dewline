Getting started

Set up Dewline in about fifteen minutes: add the theme, pick a style, then set your logo, colors and fonts.

Add Dewline to your store

  1. In your Shopify admin, go to Online Store > Themes.
  2. Select Visit Theme Store and search for Dewline.
  3. Choose the style you want to start from (Dewline, Pigment or Tonic). You can preview each one first.
  4. Select Try theme to add it to your theme library. Nothing changes on your live store yet.
  5. In Online Store > Themes, find Dewline in your theme library and select Customize to open the theme editor.
  6. When you are ready, select Publish from the theme library.

Tip: Dewline ships with demo content for the home page, product page, quiz and glossary. Edit it in the theme editor rather than starting from an empty page.

Choose a style

Dewline includes three styles. A style is a set of theme settings: colors, fonts, corner radius and button shape. Your sections and content stay the same.

  • Dewline: clean and clinical, for skincare.
  • Pigment: bold color and uppercase headings, for makeup.
  • Tonic: warm and earthy, for supplements and wellness.

Read the Styles guide for exactly what each style sets.

Where theme settings live

In the theme editor, select the Theme settings icon (the gear) in the left sidebar. You will find these groups:

Group What it controls
Logo and favicon Logo image, logo width, favicon
Colors Four color schemes used by every section
Typography Heading and body fonts, sizes, heading letter case
Layout Page width, corner radius, button shape, reveal on scroll
Product cards Image shape, hover image, vendor, subtitle, rating, quick add, tag badges
Cart Drawer or page, order notes, free shipping bar, cart recommendations, currency codes
Search Suggestions as you type, prices in suggestions
Social media Links shown in the footer

Section settings (like a hero image or a heading) are on the section itself: select the section in the left sidebar.

Add your logo

  1. Open Theme settings > Logo and favicon.
  2. Under Logo, select an image. A PNG or SVG with a transparent background works best.
  3. Adjust Logo width (60 to 260 px) until it looks balanced in the header.
  4. Add a Favicon. It shows at 32 x 32 px, so use a simple mark.

Without a logo, the header shows your store name as text.

Set your colors

Dewline uses color schemes. Each scheme has eight colors:

  • Background and Surface (product image backgrounds, panels and cards)
  • Text and Secondary text
  • Accent (badges, highlights and links)
  • Button and Button label
  • Borders

To change them:

  1. Open Theme settings > Colors.
  2. Select a scheme to edit its colors. Changes apply everywhere that scheme is used.
  3. To change which scheme a section uses, select the section and change its Color scheme setting.

Tip: Keep enough contrast between Text and Background, and between Button and Button label. Aim for a contrast ratio of at least 4.5:1 so everyone can read your store.

Set your fonts

  1. Open Theme settings > Typography.
  2. Choose a Heading font and a Body font from the Shopify font library.
  3. Use Heading size (80 to 140%) and Body size (90 to 120%) to scale text up or down.
  4. Set Heading letter case to Uppercase for a bolder look, or keep Default.

Set the layout

In Theme settings > Layout:

  • Page width: the widest your content gets, from 1100 to 1600 px.
  • Corner radius: rounding for images, cards and panels (0 to 28 px).
  • Button shape: pill, rounded or square.
  • Reveal sections on scroll: a gentle fade as sections come into view. It turns off automatically for visitors who prefer reduced motion.

Routine quiz

The routine quiz asks shoppers a few questions, one at a time, then recommends a routine with its products and an Add my routine to bag button. It is built entirely from theme editor blocks, so you do not need an app.

How it works

  • The quiz has questions, each with answers, and results.
  • Every answer gives points to one or more result keys, like dry or oily.
  • When the shopper finishes, the result with the most points is shown.
  • If two results tie, the one higher in your block list wins. If no answer scored at all, the first result shows.
  • The last result is remembered in the shopper's browser, so returning visitors see a See your last result button.

Create the quiz page

  1. In your Shopify admin, go to Online Store > Pages and select Add page.
  2. Enter a title, for example "Find your routine". You can leave the content empty.
  3. Under Theme template, choose quiz (the page.quiz template).
  4. Select Save.
  5. Add the page to your menu in Online Store > Navigation so shoppers can find it.

The quiz template ships with five sample questions and four results (dry, oily, sensitive and dull skin). Edit them to match your products.

Open the quiz in the theme editor

  1. Go to Online Store > Themes and select Customize.
  2. From the page selector at the top, choose Pages > quiz.
  3. Select the Routine quiz section in the left sidebar.

In the section settings you can change the eyebrow, heading, intro text, color scheme and spacing. Italic text in the heading shows in the accent color.

Edit questions

  1. Under the Routine quiz section, select a Question block.
  2. Set the Question text and optional Help text shown underneath.
  3. Under Answers, choose:
    • Choose one: the shopper picks a single answer.
    • Choose any: the shopper can pick several. Every checked answer adds its points.
  4. To add a question, select Add block > Question. Drag blocks to reorder them.

The quiz shows questions in the order of the blocks. Keep it short: four to six questions is the sweet spot.

Edit answers

Each Question block holds Answer blocks.

  1. Select an Answer under its question.
  2. Set the Answer label, an optional one-line Description and an optional Image (shown as a small square).
  3. Fill in Results it favors with result keys.

The points format

Results it favors is a list of result keys separated by commas. Each key is worth 1 point. Add a colon and a number to give it more weight.

You type Points given
dry dry +1
dry:2 dry +2
dry, sensitive dry +1, sensitive +1
sensitive:3, dry sensitive +3, dry +1
oily:1.5 oily +1.5

Rules to keep in mind:

  • Keys are not case sensitive. Dry and dry are the same.
  • Spaces around commas and colons are ignored.
  • Use a weight of 1 or more. A weight of 0, or anything that is not a number, counts as 1.
  • An answer key that matches no result is simply ignored.

Edit results

  1. Select a Result block under the Routine quiz section.
  2. Set the Result key. This is the word answers point to, for example dry. Use letters only, and make each key unique.
  3. Write the Heading and Text the shopper sees.
  4. Under Routine products, select up to six products in the order they are used.
  5. Optional: pick a Collection link ("Shop the full edit") and add an Offer note, such as a discount code.

The result shows the products as numbered steps with a running total. Shoppers can uncheck products they already own, then select Add my routine to bag to add the rest in one go. Sold-out products show as unavailable and are skipped.

Tip: while editing, select a Question or Result block in the sidebar and the preview jumps straight to it.

Tips

  • Give every result a fair chance. Count how many points each key can earn across all questions. If one key can earn far more, it will win too often.
  • Use weights for strong signals. An answer like "It stings or turns red quickly" is a clear sign of sensitive skin, so give it sensitive:3.
  • Put your most general result first. It wins ties and shows when nothing scored.
  • Test it yourself. Preview the page and take the quiz with different answers to check every result can win.
  • Link to it everywhere. Add a button to the quiz from your hero, a rich text section or the menu.
  • Without JavaScript, the page lists every result so shoppers can still browse the routines.
